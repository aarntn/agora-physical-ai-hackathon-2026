# Team workflow

Clone the repository. Keep main demo-ready. Create short-lived feature branches from main; commit small changes, push, open a PR, review and squash merge. Pull main before integrating. Never commit secrets or real user recordings. Confirm pre-event code rules before implementation.

## Team coordination
Three workstreams: hardware, voice/backend, product/UI and integration. Agree ownership at kickoff. Track blockers in Issues. Integrate the smallest end-to-end sensor-to-response loop first. Freeze features 30 minutes before submission; record a backup demo.

## Definition of done
- Reproducible setup
- Tested normal and failure cases
- No secrets or sensitive data
- Clear hardware requirements and known limitations
