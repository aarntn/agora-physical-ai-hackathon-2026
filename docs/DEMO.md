# Demo plan
Round 1 video <=120s; judges do not run code. Show actual hardware, not mockups masquerading as working functionality.
| Time | Content |
|---|---|
| 0–10s | Specific user and problem |
| 10–20s | Physical device and one-sentence solution |
| 20–65s | Real sensor input → Agora interaction → real response |
| 65–90s | Novel interaction and recovery/correction |
| 90–105s | Measured test result and concrete benefit |
| 105–120s | Architecture, exact Agora role and limitations |
Record early backup and final take. Avoid copyrighted music, credentials and personal data. Check audio and readable text. Final slot five minutes; confirm pitch/Q&A allocation; stage powered device, hotspot and offline backup video. No extra time for technical issues.
